📌 Краткий конспект

Как решать задачи на LeetCode
1. Пойми задачу — перескажи своими словами, найди ограничения.
2. Придумай брутфорс — даже если он медленный.
3. Оптимизируй — какой паттерн подходит? (Two Pointers, HashMap, DP...)
4. Напиши код — с комментариями и обработкой краевых случаев.
5. Протестируй — минимальные, максимальные, пустые входные данные.

🔄 Сортировки — Базовые алгоритмы

Bubble Sort — Пузырьковая сортировка

Идея: Сравниваем соседние элементы и меняем их местами, если они в неправильном порядке. "Большие" элементы "всплывают" в конец, как пузырьки.

Сложность: O(n²) время, O(1) память

Когда использовать: Только для обучения! На собеседовании могут попросить написать, но в реальных задачах используй Arrays.sort().

Java
// Bubble Sort — для понимания принципа
public void bubbleSort(int[] arr) {
    int n = arr.length;
    boolean swapped;  // Флаг оптимизации: если за проход ничего не менялось — массив уже отсортирован

    for (int i = 0; i < n - 1; i++) {
        swapped = false;  // Сбрасываем флаг в начале каждого прохода
        
        // Последний i элементов уже на своих местах, не трогаем их
        for (int j = 0; j < n - i - 1; j++) {
            // Если текущий элемент больше следующего — меняем местами
            if (arr[j] > arr[j + 1]) {
                // Обмен через временную переменную
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = true;  // Запоминаем, что была перестановка
            }
        }
        
        // Если за весь проход ничего не поменялось — массив отсортирован, выходим
        if (!swapped) break;
    }
}

// 💡 На LeetCode: почти никогда не пиши сортировку вручную!
// Используй: Arrays.sort(arr);  // O(n log n), Dual-Pivot Quicksort
Quick Sort — Быстрая сортировка (рекурсивная)

Идея: Divide and Conquer. Выбираем "опорный" элемент (pivot), разделяем массив на две части: меньше pivot и больше pivot, рекурсивно сортируем части.

Сложность: O(n log n) среднее, O(n²) худшее, O(log n) память (стек рекурсии)

Java
// Quick Sort — понимание рекурсии и partition
public void quickSort(int[] arr, int left, int right) {
    // Базовый случай рекурсии: если подмассив из 0 или 1 элемента — он уже отсортирован
    if (left >= right) return;

    // Partition: размещаем pivot на своё место, возвращаем его индекс
    int pivotIndex = partition(arr, left, right);

    // Рекурсивно сортируем левую и правую части
    quickSort(arr, left, pivotIndex - 1);   // Элементы < pivot
    quickSort(arr, pivotIndex + 1, right);  // Элементы > pivot
}

// Partition: Lomuto scheme (проще для понимания)
private int partition(int[] arr, int left, int right) {
    // Выбираем pivot — последний элемент (можно выбрать случайно для улучшения)
    int pivot = arr[right];
    int i = left - 1;  // Индекс последнего элемента, который < pivot

    for (int j = left; j < right; j++) {
        // Если текущий элемент меньше pivot — "поднимаем" его в левую часть
        if (arr[j] <= pivot) {
            i++;  // Расширяем левую часть
            swap(arr, i, j);  // Меняем местами текущий элемент с границей левой части
        }
    }
    
    // Ставим pivot на своё место — между левой и правой частями
    swap(arr, i + 1, right);
    return i + 1;  // Возвращаем индекс pivot
}

// Вспомогательный метод для обмена
private void swap(int[] arr, int i, int j) {
    int temp = arr[i];
    arr[i] = arr[j];
    arr[j] = temp;
}
Merge Sort — Сортировка слиянием

Идея: Divide and Conquer. Делим массив пополам, рекурсивно сортируем половины, затем сливаем две отсортированные половины в одну.

Сложность: O(n log n) всегда, O(n) дополнительная память

Плюсы: Стабильная сортировка, предсказуемая сложность. Часто спрашивают на собеседованиях.

Java
// Merge Sort — стабильная, предсказуемая сложность
public void mergeSort(int[] arr, int left, int right) {
    if (left >= right) return;  // Базовый случай: 1 элемент уже отсортирован

    // Делим массив пополам (mid = середина)
    int mid = left + (right - left) / 2;  // Так безопаснее, чем (left+right)/2 (переполнение)

    // Рекурсивно сортируем левую и правую половины
    mergeSort(arr, left, mid);
    mergeSort(arr, mid + 1, right);

    // Сливаем две отсортированные половины
    merge(arr, left, mid, right);
}

// Merge: сливаем arr[left..mid] и arr[mid+1..right] в один отсортированный массив
private void merge(int[] arr, int left, int mid, int right) {
    // Создаём временные массивы для левой и правой частей
    int n1 = mid - left + 1;
    int n2 = right - mid;
    int[] L = new int[n1];
    int[] R = new int[n2];

    // Копируем данные во временные массивы
    for (int i = 0; i < n1; i++) L[i] = arr[left + i];
    for (int j = 0; j < n2; j++) R[j] = arr[mid + 1 + j];

    // Сливаем временные массивы обратно в arr[left..right]
    int i = 0, j = 0, k = left;  // i — индекс в L, j — в R, k — в arr

    while (i < n1 && j < n2) {
        // Берём меньший элемент из двух массивов
        if (L[i] <= R[j]) {
            arr[k++] = L[i++];  // Берём из L, увеличиваем i и k
        } else {
            arr[k++] = R[j++];  // Берём из R, увеличиваем j и k
        }
    }

    // Копируем оставшиеся элементы (один из массивов уже пуст)
    while (i < n1) arr[k++] = L[i++];  // Остались в L
    while (j < n2) arr[k++] = R[j++];  // Остались в R
}

🔍 Поиск — Linear и Binary Search

Linear Search — Линейный поиск

Идея: Проходим по массиву слева направо, сравниваем каждый элемент с искомым.

Сложность: O(n) время, O(1) память

Когда использовать: Маленькие массивы, неотсортированные данные, или когда нужно найти ВСЕ вхождения.

Java
// Linear Search — простой, но медленный для больших массивов
public int linearSearch(int[] arr, int target) {
    // Проходим по ВСЕМ элементам
    for (int i = 0; i < arr.length; i++) {
        // Нашли! Возвращаем индекс
        if (arr[i] == target) {
            return i;
        }
    }
    // Не нашли — возвращаем -1 (стандартное соглашение в задачах)
    return -1;
}

// 💡 На LeetCode: используй, когда массив маленький (<100 элементов) или неотсортированный
Binary Search — Бинарный поиск (итеративный)

Идея: Массив отсортирован? Делим пополам, сравниваем середину с target, отбрасываем половину, повторяем.

Сложность: O(log n) время, O(1) память

Когда использовать: Отсортированный массив, поиск элемента, поиск границы (первый/последний), поиск в rotated array.

Java
// Binary Search — ИТЕРАТИВНЫЙ (предпочтительный, нет риска переполнения стека)
public int binarySearch(int[] arr, int target) {
    int left = 0;                    // Левая граница поиска
    int right = arr.length - 1;    // Правая граница поиска

    // Пока есть где искать (left <= right)
    while (left <= right) {
        // Находим середину БЕЗ переполнения: left + (right-left)/2
        int mid = left + (right - left) / 2;

        // Нашли target!
        if (arr[mid] == target) {
            return mid;
        }
        // Target в левой половине — сужаем правую границу
        else if (arr[mid] > target) {
            right = mid - 1;  // mid уже проверили, исключаем его
        }
        // Target в правой половине — сужаем левую границу
        else {
            left = mid + 1;   // mid уже проверили, исключаем его
        }
    }

    // Не нашли
    return -1;
}

// 💡 Шаблон для запоминания:
// while (left <= right) { int mid = left + (right-left)/2; if (arr[mid]==target) return mid; else if (arr[mid]>target) right=mid-1; else left=mid+1; }
Binary Search — Рекурсивный вариант
Java
// Binary Search — РЕКУРСИВНЫЙ (красиво, но риск StackOverflow для очень больших массивов)
public int binarySearchRecursive(int[] arr, int target, int left, int right) {
    // Базовый случай: не нашли
    if (left > right) return -1;

    int mid = left + (right - left) / 2;

    if (arr[mid] == target) {
        return mid;
    } else if (arr[mid] > target) {
        // Ищем в левой половине
        return binarySearchRecursive(arr, target, left, mid - 1);
    } else {
        // Ищем в правой половине
        return binarySearchRecursive(arr, target, mid + 1, right);
    }
}

// Вызов: binarySearchRecursive(arr, target, 0, arr.length - 1);

👉 Two Pointers — Два указателя

Паттерн: Схождение с двух концов

Идея: Один указатель в начале, другой в конце. Двигаем их навстречу друг другу в зависимости от условия.

Когда использовать: Отсортированный массив, поиск пары с заданной суммой, проверка палиндрома, удаление дубликатов.

Сложность: O(n) время, O(1) память

Java
// Задача: Two Sum II — Input Array Is Sorted (LeetCode 167)
// Дано: отсортированный массив, найти два числа, сумма которых = target
public int[] twoSumSorted(int[] numbers, int target) {
    int left = 0;                          // Левый указатель — начало
    int right = numbers.length - 1;      // Правый указатель — конец

    // Пока указатели не встретились
    while (left < right) {
        int sum = numbers[left] + numbers[right];

        if (sum == target) {
            // Нашли! Возвращаем индексы (1-based, как в задаче)
            return new int[] {left + 1, right + 1};
        }
        // Сумма слишком маленькая — двигаем left вправо (увеличиваем сумму)
        else if (sum < target) {
            left++;
        }
        // Сумма слишком большая — двигаем right влево (уменьшаем сумму)
        else {
            right--;
        }
    }

    // По условию задачи гарантируется решение, но на всякий случай:
    return new int[] {-1, -1};
}

// 💡 Почему это работает? Массив отсортирован!
// Если сумма мала — нужно взять число побольше → left++
// Если сумма велика — нужно взять число поменьше → right--
Паттерн: Быстрый и медленный указатели (Floyd's Cycle)

Идея: Один указатель движется быстрее другого. Если есть цикл — они встретятся.

Когда использовать: Обнаружение цикла в связном списке, поиск середины списка, удаление N-го элемента с конца.

Java
// Задача: Linked List Cycle (LeetCode 141)
// Определить, есть ли цикл в связном списке
public boolean hasCycle(ListNode head) {
    if (head == null) return false;

    ListNode slow = head;   // Медленный: 1 шаг за итерацию
    ListNode fast = head;   // Быстрый: 2 шага за итерацию

    // Пока fast может сделать 2 шага
    while (fast != null && fast.next != null) {
        slow = slow.next;           // slow += 1
        fast = fast.next.next;     // fast += 2

        // Если встретились — есть цикл!
        if (slow == fast) {
            return true;
        }
    }

    // fast достиг конца — цикла нет
    return false;
}

// 💡 Почему это работает? Если есть цикл, fast "догонит" slow внутри цикла.
// Разница в скорости = 1 шаг/итерацию → гарантированная встреча.

🪟 Sliding Window — Скользящее окно

Паттерн: Фиксированное окно

Идея: Окно фиксированного размера "скользит" по массиву. Добавляем новый элемент справа, удаляем старый слева.

Когда использовать: Найти максимум/сумму/среднее подмассива фиксированной длины.

Сложность: O(n) вместо O(n*k) у брутфорса!

Java
// Задача: Maximum Sum Subarray of Size K (аналог LeetCode)
// Найти максимальную сумму подмассива длины k
public int maxSumSubarray(int[] arr, int k) {
    int maxSum = Integer.MIN_VALUE;  // Инициализируем минимальным значением
    int windowSum = 0;                 // Текущая сумма окна
    int windowStart = 0;               // Левая граница окна

    for (int windowEnd = 0; windowEnd < arr.length; windowEnd++) {
        // 1. Добавляем новый элемент в окно (справа)
        windowSum += arr[windowEnd];

        // 2. Когда окно достигло размера k — считаем и сдвигаем
        if (windowEnd >= k - 1) {
            // Обновляем максимум
            maxSum = Math.max(maxSum, windowSum);

            // 3. Удаляем элемент слева и сдвигаем окно
            windowSum -= arr[windowStart];
            windowStart++;
        }
    }

    return maxSum;
}

// 💡 Почему O(n)? Каждый элемент добавляется и удаляется из окна ровно 1 раз.
Паттерн: Динамическое окно (переменной длины)

Идея: Окно расширяется, пока условие выполняется, затем сжимается, пока условие не нарушится.

Когда использовать: Найти минимальную/максимальную подстроку с условием (без повторов, с определённым набором символов).

Java
// Задача: Longest Substring Without Repeating Characters (LeetCode 3)
// Найти длину самой длинной подстроки без повторяющихся символов
public int lengthOfLongestSubstring(String s) {
    int maxLen = 0;                          // Результат
    int left = 0;                             // Левая граница окна
    java.util.HashSet<Character> seen = new java.util.HashSet<>();  // Храним символы в окне

    for (int right = 0; right < s.length(); right++) {
        char curr = s.charAt(right);

        // Если символ уже в окне — сжимаем окно слева, пока не уберём дубликат
        while (seen.contains(curr)) {
            seen.remove(s.charAt(left));  // Удаляем левый символ из множества
            left++;                       // Сдвигаем левую границу
        }

        // Добавляем текущий символ в окно
        seen.add(curr);

        // Обновляем максимум: правая граница - левая + 1 = длина окна
        maxLen = Math.max(maxLen, right - left + 1);
    }

    return maxLen;
}

// 💡 Ключевая идея: while-цикл "сжимает" окно, пока условие не выполнится.
// Это гарантирует, что в окне всегда нет дубликатов.

🗂️ HashMap / HashSet — Паттерны поиска

Паттерн: Поиск пары за один проход

Идея: Проходим по массиву один раз. Для каждого элемента проверяем: есть ли в HashMap нужное дополнение (target - current). Если нет — сохраняем текущий элемент.

Когда использовать: Two Sum, поиск дубликатов, подсчёт частот.

Сложность: O(n) время, O(n) память

Java
// Задача: Two Sum (LeetCode 1) — КЛАССИКА!
// Найти два индекса, сумма значений которых = target
public int[] twoSum(int[] nums, int target) {
    // HashMap: key = значение из массива, value = его индекс
    java.util.HashMap<Integer, Integer> map = new java.util.HashMap<>();

    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];  // Какое число нужно, чтобы получить target?

        // Если дополнение уже есть в карте — мы нашли пару!
        if (map.containsKey(complement)) {
            return new int[] {map.get(complement), i};
        }

        // Сохраняем текущее значение и его индекс для будущих проверок
        map.put(nums[i], i);
    }

    // По условию задачи решение гарантировано, но на всякий случай:
    return new int[] {-1, -1};
}

// 💡 Почему это работает? Мы ищем "прошлое": для текущего nums[i] проверяем,
// встречали ли мы раньше число (target - nums[i]). Если да — пара найдена!
Паттерн: Подсчёт частот (Frequency Map)
Java
// Задача: Contains Duplicate II (LeetCode 219)
// Есть ли два одинаковых числа на расстоянии ≤ k?
public boolean containsNearbyDuplicate(int[] nums, int k) {
    // HashMap: key = число, value = последний индекс, где оно встречалось
    java.util.HashMap<Integer, Integer> lastIndex = new java.util.HashMap<>();

    for (int i = 0; i < nums.length; i++) {
        if (lastIndex.containsKey(nums[i])) {
            int prevIdx = lastIndex.get(nums[i]);
            // Проверяем расстояние между текущим и предыдущим вхождением
            if (i - prevIdx <= k) {
                return true;  // Нашли дубликат в пределах k!
            }
        }
        // Обновляем последний индекс для этого числа
        lastIndex.put(nums[i], i);
    }

    return false;
}

📦 Stack / Queue — Стек и Очередь

Паттерн: Valid Parentheses (Стек)

Идея: Открывающая скобка — кладём в стек. Закрывающая — проверяем, что верх стека — соответствующая открывающая.

Когда использовать: Проверка скобок, обратный порядок, undo-операции, DFS.

Java
// Задача: Valid Parentheses (LeetCode 20)
public boolean isValid(String s) {
    // Стек для хранения открывающих скобок
    java.util.Stack<Character> stack = new java.util.Stack<>();

    // Карта: закрывающая скобка → соответствующая открывающая
    java.util.Map<Character, Character> pairs = Map.of(
        ')', '(',
        ']', '[',
        '}', '{'
    );

    for (char c : s.toCharArray()) {
        // Если открывающая скобка — кладём в стек
        if (c == '(' || c == '[' || c == '{') {
            stack.push(c);
        }
        // Если закрывающая — проверяем соответствие
        else {
            // Стек пуст или верхний элемент не соответствует — ошибка
            if (stack.isEmpty() || stack.pop() != pairs.get(c)) {
                return false;
            }
        }
    }

    // В конце стек должен быть пуст (все скобки закрыты)
    return stack.isEmpty();
}

// 💡 Ключевая идея: закрывающая скобка должна соответствовать ПОСЛЕДНЕЙ
// не закрытой открывающей — это идеально для стека (LIFO)!
Паттерн: Монотонный стек (Next Greater Element)
Java
// Задача: Next Greater Element I (LeetCode 496)
// Для каждого элемента найти первый больший элемент справа
public int[] nextGreaterElement(int[] nums1, int[] nums2) {
    // Стек хранит индексы элементов, для которых ещё не нашли больший
    java.util.Stack<Integer> stack = new java.util.Stack<>();
    // Карта: элемент → его следующий больший
    java.util.Map<Integer, Integer> nextGreater = new java.util.HashMap<>();

    for (int num : nums2) {
        // Пока текущий элемент больше верхнего в стеке — он для него "следующий больший"
        while (!stack.isEmpty() && num > stack.peek()) {
            nextGreater.put(stack.pop(), num);
        }
        stack.push(num);  // Текущий элемент ждёт своего "большего"
    }

    // Формируем ответ для nums1
    int[] result = new int[nums1.length];
    for (int i = 0; i < nums1.length; i++) {
        result[i] = nextGreater.getOrDefault(nums1[i], -1);
    }

    return result;
}

// 💡 Монотонный стек: элементы в стеке идут в убывающем порядке.
// Когда приходит больший элемент — он "выталкивает" меньшие, становясь для них ответом.

🔁 Рекурсия и Бэктрекинг

Паттерн: Базовая рекурсия (Factorial)

Идея: Функция вызывает сама себя с уменьшенным входом. Обязательно: базовый случай (остановка) + прогресс к нему.

Когда использовать: Факториал, числа Фибоначчи, обход деревьев, генерация комбинаций.

Java
// Факториал: n! = n * (n-1) * ... * 1
public int factorial(int n) {
    // Базовый случай: 0! = 1, 1! = 1
    if (n <= 1) {
        return 1;
    }
    // Рекурсивный случай: n! = n * (n-1)!
    return n * factorial(n - 1);
}

// 💡 Важно: всегда проверяй базовый случай ПЕРЕД рекурсивным вызовом!
// Иначе — StackOverflowError (бесконечная рекурсия).
Паттерн: Бэктрекинг (генерация комбинаций)

Идея: Пробуем добавить элемент → рекурсивно решаем подзадачу → отменяем выбор (бэктрек) → пробуем следующий вариант.

Когда использовать: Подмножества, перестановки, комбинации, судоку, N-Queens.

Java
// Задача: Subsets (LeetCode 78) — все подмножества множества
public java.util.List<java.util.List<Integer>> subsets(int[] nums) {
    java.util.List<java.util.List<Integer>> result = new java.util.ArrayList<>();
    backtrack(nums, 0, new java.util.ArrayList<>(), result);
    return result;
}

// Backtracking-функция
private void backtrack(int[] nums, int start, 
                     java.util.List<Integer> path,
                     java.util.List<java.util.List<Integer>> result) {
    
    // Добавляем текущую комбинацию в результат (включая пустую!)
    result.add(new java.util.ArrayList<>(path));  // Копируем, т.к. path будет меняться!

    // Пробуем добавить каждый элемент, начиная с start
    for (int i = start; i < nums.length; i++) {
        // 1. Выбрать: добавляем nums[i] в текущий путь
        path.add(nums[i]);

        // 2. Исследовать: рекурсивно генерируем подмножества с оставшихся элементов
        backtrack(nums, i + 1, path, result);  // i+1, чтобы не повторять элементы

        // 3. Отменить выбор (БЭКТРЕК): убираем последний элемент, пробуем следующий вариант
        path.remove(path.size() - 1);
    }
}

// 💡 Шаблон бэктрекинга:
// 1. Добавить текущий выбор в path
// 2. Рекурсивный вызов с обновлёнными параметрами
// 3. Убрать выбор (откат) — это КЛЮЧЕВОЙ шаг!

🧮 Dynamic Programming — Динамическое программирование

Паттерн: 1D DP (Climbing Stairs)

Идея: Решение большой задачи через решение меньших подзадач. Запоминаем результаты, чтобы не пересчитывать.

Когда использовать: Оптимизация, подсчёт способов, минимальная стоимость, перекрывающиеся подзадачи.

Два подхода: Top-down (рекурсия + мемоизация) и Bottom-up (итерация + таблица).

Java
// Задача: Climbing Stairs (LeetCode 70)
// Сколько способов подняться по лестнице из n ступенек, если можно шагать на 1 или 2?

// ── BOTTOM-UP (итеративный, предпочтительный) ──
public int climbStairs(int n) {
    // Базовые случаи
    if (n <= 2) return n;  // 1 ступенька: 1 способ, 2 ступеньки: 2 способа

    // dp[i] = количество способов дойти до i-й ступеньки
    // Рекуррентная формула: dp[i] = dp[i-1] + dp[i-2]
    // (можно прийти с (i-1) шагом в 1 или с (i-2) шагом в 2)

    int prev2 = 1;  // dp[1] — два шага назад
    int prev1 = 2;  // dp[2] — один шаг назад
    int curr = 0;   // dp[i] — текущее

    for (int i = 3; i <= n; i++) {
        curr = prev1 + prev2;  // dp[i] = dp[i-1] + dp[i-2]
        // Сдвигаем "окно" вперёд
        prev2 = prev1;
        prev1 = curr;
    }

    return curr;
}

// 💡 Оптимизация памяти: нам не нужен весь массив dp[],
// достаточно хранить только два предыдущих значения → O(1) память!
Паттерн: 2D DP (Grid Unique Paths)
Java
// Задача: Unique Paths (LeetCode 62)
// Сколько путей из левого верхнего в правый нижний угол сетки m×n?
// Можно двигаться только вправо или вниз.

public int uniquePaths(int m, int n) {
    // dp[i][j] = количество путей до клетки (i, j)
    int[][] dp = new int[m][n];

    // Базовый случай: первая строка и первый столбец — только 1 путь (прямо)
    for (int i = 0; i < m; i++) dp[i][0] = 1;  // Первый столбец
    for (int j = 0; j < n; j++) dp[0][j] = 1;  // Первая строка

    // Заполняем таблицу: в клетку (i,j) можно прийти сверху или слева
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            dp[i][j] = dp[i-1][j] + dp[i][j-1];  // Сверху + Слева
        }
    }

    return dp[m-1][n-1];  // Ответ в правом нижнем углу
}

// 💡 Рекуррентная формула — сердце ДП! Сначала определи её, потом кодируй.

🌳 Деревья — BFS и DFS

Паттерн: DFS — Рекурсивный обход

Идея: Идём вглубь до конца, затем возвращаемся (backtrack). Три порядка: Pre-order (корень-левый-правый), In-order (левый-корень-правый), Post-order (левый-правый-корень).

Когда использовать: Обход дерева, поиск пути, проверка условий, сериализация.

Java
// Задача: Maximum Depth of Binary Tree (LeetCode 104)
public int maxDepth(TreeNode root) {
    // Базовый случай: пустое дерево имеет глубину 0
    if (root == null) {
        return 0;
    }

    // Рекурсивно считаем глубину левого и правого поддеревьев
    int leftDepth = maxDepth(root.left);
    int rightDepth = maxDepth(root.right);

    // Глубина текущего узла = 1 (сам узел) + максимум из глубин детей
    return 1 + Math.max(leftDepth, rightDepth);
}

// 💡 Шаблон рекурсивного DFS для дерева:
// 1. Проверка на null (база)
// 2. Рекурсивные вызовы для left и right
// 3. Комбинация результатов + обработка текущего узла
Паттерн: BFS — Обход по уровням

Идея: Используем очередь (Queue). Обрабатываем узлы уровень за уровнем: добавляем детей в очередь, пока очередь не пуста.

Когда использовать: Поиск кратчайшего пути, обход по уровням, проверка "соседей".

Java
// Задача: Binary Tree Level Order Traversal (LeetCode 102)
public java.util.List<java.util.List<Integer>> levelOrder(TreeNode root) {
    java.util.List<java.util.List<Integer>> result = new java.util.ArrayList<>();
    if (root == null) return result;

    // Очередь для BFS
    java.util.Queue<TreeNode> queue = new java.util.LinkedList<>();
    queue.offer(root);  // Начинаем с корня

    while (!queue.isEmpty()) {
        int levelSize = queue.size();  // Количество узлов на текущем уровне
        java.util.List<Integer> currentLevel = new java.util.ArrayList<>();

        // Обрабатываем ВСЕ узлы текущего уровня
        for (int i = 0; i < levelSize; i++) {
            TreeNode node = queue.poll();  // Берём узел из очереди
            currentLevel.add(node.val);   // Добавляем его значение

            // Добавляем детей в очередь для следующего уровня
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }

        result.add(currentLevel);  // Добавляем уровень в результат
    }

    return result;
}

// 💡 Ключевой момент: levelSize = queue.size() в начале цикла фиксирует
// количество узлов на ТЕКУЩЕМ уровне, прежде чем мы добавим детей.

🕸️ Графы — BFS, DFS, Union Find

Паттерн: Number of Islands (DFS на матрице)

Идея: Проходим по всем клеткам. Если видим '1' (земля) — запускаем DFS, чтобы "закрасить" весь остров (пометить как посещённый). Считаем количество запусков DFS.

Когда использовать: Связные компоненты, заливка, поиск областей.

Java
// Задача: Number of Islands (LeetCode 200)
public int numIslands(char[][] grid) {
    if (grid == null || grid.length == 0) return 0;

    int count = 0;
    int rows = grid.length;
    int cols = grid[0].length;

    // Проходим по всем клеткам
    for (int r = 0; r < rows; r++) {
        for (int c = 0; c < cols; c++) {
            // Если нашли землю — новый остров!
            if (grid[r][c] == '1') {
                count++;  // Увеличиваем счётчик
                dfs(grid, r, c, rows, cols);  // "Закрашиваем" весь остров
            }
        }
    }

    return count;
}

// DFS: помечаем все клетки острова как посещённые ('0')
private void dfs(char[][] grid, int r, int c, int rows, int cols) {
    // Проверка границ и "воды" / уже посещённых
    if (r < 0 || r >= rows || c < 0 || c >= cols || grid[r][c] != '1') {
        return;
    }

    // Помечаем как посещённую (чтобы не зайти снова)
    grid[r][c] = '0';

    // Рекурсивно обходим 4 направления: вверх, вниз, влево, вправо
    dfs(grid, r-1, c, rows, cols);  // Вверх
    dfs(grid, r+1, c, rows, cols);  // Вниз
    dfs(grid, r, c-1, rows, cols);  // Влево
    dfs(grid, r, c+1, rows, cols);  // Вправо
}

// 💡 Важно: меняем grid[r][c] на '0' ПЕРЕД рекурсивными вызовами,
// иначе можно зациклиться между соседними клетками!
Паттерн: Union Find (Disjoint Set Union)
Java
// Union Find — для задач на связность (LeetCode 200, 547, 684)
class UnionFind {
    private int[] parent;  // parent[i] = родитель узла i
    private int[] rank;    // rank[i] = "высота" дерева для оптимизации
    private int count;     // Количество компонент связности

    public UnionFind(int n) {
        count = n;
        parent = new int[n];
        rank = new int[n];
        // Изначально каждый узел — сам себе родитель
        for (int i = 0; i < n; i++) {
            parent[i] = i;
            rank[i] = 1;
        }
    }

    // Найти корень с оптимизацией: Path Compression
    public int find(int x) {
        if (parent[x] != x) {
            // "Сплющиваем" дерево: делаем всех предков прямыми детьми корня
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }

    // Объединить две компоненты с оптимизацией: Union by Rank
    public boolean union(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);

        // Если уже в одной компоненте — не нужно объединять
        if (rootX == rootY) return false;

        // Прикрепляем меньшее дерево к большему (по rank)
        if (rank[rootX] > rank[rootY]) {
            parent[rootY] = rootX;
        } else if (rank[rootX] < rank[rootY]) {
            parent[rootX] = rootY;
        } else {
            parent[rootY] = rootX;
            rank[rootX]++;  // Ранг увеличился
        }

        count--;  // Количество компонент уменьшилось на 1
        return true;
    }

    public int getCount() {
        return count;
    }
}

// 💡 Оптимизации:
// 1. Path Compression: find() делает дерево плоским → почти O(1)
// 2. Union by Rank: объединяем по высоте → дерево остаётся сбалансированным
// Амортизированная сложность: ~O(α(n)) ≈ O(1), где α — обратная функция Аккермана
