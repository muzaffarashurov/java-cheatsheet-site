Email / JavaMailSender

Spring Email Thymeleaf SMTP

JavaMailSender, MimeMessage, HTML письма, вложения, Thymeleaf шаблоны, асинхронная отправка, тестирование с MailHog — полный разбор отправки email в Spring Boot.

📌 Краткий конспект
Ключевые компоненты
JavaMailSender — интерфейс Spring для отправки email. Автоконфигурируется при наличии spring-boot-starter-mail.
MimeMessage — сложное сообщение: HTML, вложения, inline изображения.
SimpleMailMessage — простое текстовое сообщение.
Класс/ИнтерфейсНазначение
JavaMailSenderОсновной интерфейс для отправки. send(SimpleMailMessage), send(MimeMessage)
SimpleMailMessageПростое текстовое письмо без HTML и вложений
MimeMessageМногофункциональное MIME сообщение
MimeMessageHelperУдобный Builder для MimeMessage
TemplateEngineThymeleaf движок для HTML шаблонов

</dependency>

<!-- Thymeleaf для HTML шаблонов (опционально) -->
<dependency>
  <groupId>org.springframework.boot</groupId>

</dependency>
YAML — application.yml
spring:
  mail:
    host: ${MAIL_HOST:smtp.gmail.com}        # SMTP сервер
    port: ${MAIL_PORT:587}                   # 587 = TLS, 465 = SSL, 25 = plain
    username: ${MAIL_USERNAME}               # логин SMTP
    password: ${MAIL_PASSWORD}               # пароль или App Password
    properties:
      mail:
        smtp:
          auth: true                         # аутентификация
          starttls:
            enable: true                     # STARTTLS (для порта 587)
            required: true
          connectiontimeout: 5000            # таймаут соединения мс
          timeout: 5000                      # таймаут чтения мс
          writetimeout: 5000                 # таймаут записи мс
    default-encoding: UTF-8

# ── Кастомные свойства приложения
app:
  mail:
    from: noreply@myapp.com                  # адрес отправителя
    from-name: My Application               # имя отправителя
    base-url: ${APP_BASE_URL:http://localhost:8080}  # для ссылок в письмах
💡 Gmail App Password
Для Gmail нужен App Password (не обычный пароль): Google Account → Security → 2-Step Verification → App passwords. Обычный пароль не работает с SMTP если включена 2FA.
✉️ SimpleMailMessage — текстовое письмо

SimpleMailMessage — для простых текстовых писем без HTML и вложений. Не поддерживает кириллицу в некоторых клиентах — используй MimeMessage для надёжности.

🌐 MimeMessage — HTML письма

MimeMessage + MimeMessageHelper — для HTML контента, вложений и inline изображений. MimeMessageHelper(message, true) — второй параметр true включает multipart режим (нужен для вложений).

Метод MimeMessageHelperОписание

setTo(String[])Несколько получателей
setCc(String)Копия
setBcc(String)Скрытая копия
setFrom(String)Отправитель (email)
setFrom(String, String)Отправитель (email, имя)
setSubject(String)Тема письма
setText(String, boolean)Текст (второй параметр true = HTML)
addAttachment(name, file)Добавить вложение
addInline(id, resource)Встроить ресурс (картинку)
setReplyTo(String)Reply-To адрес
setPriority(int)Приоритет (1=высокий, 3=норм, 5=низкий)
📎 Вложения и Inline изображения
Attachment (вложение)
  • helper.addAttachment("report.pdf", file)
  • Файл прикрепляется к письму
  • Пользователь скачивает
  • Content-Disposition: attachment
Inline (встроенный)
  • helper.addInline("logo", resource)
  • Используется в HTML: <img src="cid:logo">
  • Встроен в тело письма
  • Content-Disposition: inline
🍃 Thymeleaf шаблоны

Thymeleaf позволяет создавать красивые HTML письма через шаблоны с переменными. Шаблоны хранятся в src/main/resources/templates/email/.

ШагДействие
1Создать HTML шаблон в templates/email/
2Инжектировать SpringTemplateEngine
3Создать Context с переменными
4Вызвать templateEngine.process("email/template", context)
5Передать результат в helper.setText(html, true)
⚡ Асинхронная отправка
⚠️ Никогда не отправляй email синхронно в HTTP запросе
SMTP запрос занимает 200-2000мс. Пользователь будет ждать. Всегда отправляй асинхронно: через @Async, через Kafka событие, или через очередь задач.
ПодходПлюсыМинусы
@AsyncПросто, встроен в SpringНет retry при ошибке
Kafka событиеRetry, надёжность, масштабированиеСложнее
Spring EventsПростая развязка в одном сервисеНет retry
Очередь задач (Quartz)Retry, scheduling, персистентностьНужна настройка
✅ Best Practices
✅ Правильно
  • Всегда отправлять асинхронно (@Async или очередь)
  • Retry логика при SMTP ошибке
  • HTML + text/plain версия (для старых клиентов)
  • В dev — MailHog/Mailtrap (не реальный SMTP)
  • Логировать успех/ошибку отправки
  • Не раскрывать SMTP пароль — ENV переменные
  • Unsubscribe ссылка в маркетинговых письмах
  • Валидировать email перед отправкой
🚫 Ошибки
  • Синхронная отправка в HTTP запросе
  • Нет обработки исключений (MailException)
  • SMTP пароль в application.yml в репозитории
  • Отправка реальных писем в тестах
  • Нет retry при временной ошибке SMTP
  • Слишком большие вложения (>10MB)
  • HTML без inline CSS (Gmail и Outlook обрезают)
💻 Примеры кода
1. EmailService — полная реализация
Java
@Service
@RequiredArgsConstructor
@Slf4j
public class EmailService {

    private final JavaMailSender    mailSender;        // Spring инжектирует авто
    private final SpringTemplateEngine templateEngine; // Thymeleaf

    @Value("${app.mail.from}")
    private String fromEmail;

    @Value("${app.mail.from-name:My App}")
    private String fromName;

    @Value("${app.mail.base-url}")
    private String baseUrl;

    // ── Простое текстовое письмо
    @Async                                            // асинхронно — не блокируем поток!
    public void sendSimple(String to, String subject, String text) {
        try {
            SimpleMailMessage message = new SimpleMailMessage();
            message.setFrom(fromEmail);
            message.setTo(to);
            message.setSubject(subject);
            message.setText(text);
            mailSender.send(message);
            log.info("Письмо отправлено: to={}, subject={}", to, subject);
        } catch (MailException e) {
            log.error("Ошибка отправки письма: to={}, error={}", to, e.getMessage());
            throw e;                                    // пробрасываем для retry
        }
    }

    // ── HTML письмо через MimeMessage
    @Async
    public void sendHtml(String to, String subject, String htmlContent) {
        try {
            MimeMessage message = mailSender.createMimeMessage();
            MimeMessageHelper helper = new MimeMessageHelper(
                message,
                true,                                  // multipart = true (для вложений)
                "UTF-8"
            );

            helper.setFrom(fromEmail, fromName);        // email + имя
            helper.setTo(to);
            helper.setSubject(subject);
            helper.setText(htmlContent, true);          // true = HTML

            mailSender.send(message);
            log.info("HTML письмо отправлено: to={}", to);
        } catch (Exception e) {
            log.error("Ошибка отправки HTML письма: to={}", to, e);
            throw new RuntimeException("Ошибка отправки письма", e);
        }
    }

    // ── Письмо с вложением
    @Async
    public void sendWithAttachment(
            String to,
            String subject,
            String htmlContent,
            String attachmentName,
            byte[] attachmentData) {
        try {
            MimeMessage message = mailSender.createMimeMessage();
            MimeMessageHelper helper = new MimeMessageHelper(message, true, "UTF-8");

            helper.setFrom(fromEmail, fromName);
            helper.setTo(to);
            helper.setSubject(subject);
            helper.setText(htmlContent, true);

            // Вложение из byte[]
            helper.addAttachment(
                attachmentName,                          // имя файла в письме
                new ByteArrayResource(attachmentData), // данные
                "application/pdf"                     // MIME тип
            );

            mailSender.send(message);
        } catch (Exception e) {
            log.error("Ошибка отправки с вложением: to={}", to, e);
            throw new RuntimeException("Ошибка отправки письма", e);
        }
    }

    // ── Письмо через Thymeleaf шаблон
    @Async
    public void sendFromTemplate(
            String to,
            String subject,
            String templateName,              // имя шаблона без расширения
            Map<String, Object> variables) {   // переменные для шаблона
        try {
            // Рендерим HTML из Thymeleaf шаблона
            Context context = new Context(Locale.forLanguageTag("ru"));
            context.setVariables(variables);          // передаём переменные
            String html = templateEngine.process(
                "email/" + templateName, context);     // рендерим шаблон

            sendHtml(to, subject, html);
        } catch (Exception e) {
            log.error("Ошибка рендера шаблона: {}", templateName, e);
            throw new RuntimeException("Ошибка отправки письма", e);
        }
    }
}
2. Типовые письма — приветствие, сброс пароля
Java
@Service
@RequiredArgsConstructor
public class NotificationService {

    private final EmailService emailService;

    @Value("${app.mail.base-url}")
    private String baseUrl;

    // ── Приветственное письмо при регистрации
    public void sendWelcome(User user) {
        Map<String, Object> vars = Map.of(
            "name",     user.getName(),
            "email",    user.getEmail(),
            "loginUrl", baseUrl + "/login"
        );
        emailService.sendFromTemplate(
            user.getEmail(),
            "Добро пожаловать в My App!",
            "welcome",                            // → templates/email/welcome.html
            vars
        );
    }

    // ── Письмо со ссылкой сброса пароля
    public void sendPasswordReset(String email, String resetToken) {
        String resetUrl = baseUrl + "/reset-password?token=" + resetToken;
        Map<String, Object> vars = Map.of(
            "resetUrl",   resetUrl,
            "expireHours", 24                       // токен действует 24 часа
        );
        emailService.sendFromTemplate(
            email,
            "Сброс пароля",
            "password-reset",                      // → templates/email/password-reset.html
            vars
        );
    }

    // ── Письмо с подтверждением заказа + PDF вложение
    public void sendOrderConfirmation(Order order, byte[] invoicePdf) {
        Map<String, Object> vars = Map.of(
            "orderId",   order.getId(),
            "total",     order.getTotal(),
            "orderUrl",  baseUrl + "/orders/" + order.getId()
        );
        String html = /* рендерим шаблон */ "";

        emailService.sendWithAttachment(
            order.getCustomerEmail(),
            "Заказ #" + order.getId() + " подтверждён",
            html,
            "invoice-" + order.getId() + ".pdf",   // имя файла вложения
            invoicePdf
        );
    }

    // ── Рассылка нескольким получателям
    public void sendBulk(List<String> emails, String subject, String html) {
        // Отправляем по одному — не через BCC (чтобы не попасть в спам)
        emails.forEach(email ->
            emailService.sendHtml(email, subject, html)
        );
        // Все вызовы асинхронные — не блокируют
    }
}

5. Юнит тест EmailService
Java
@ExtendWith(MockitoExtension.class)
class EmailServiceTest {

    @Mock
    private JavaMailSender mailSender;         // мокируем — не отправляем реальные письма!

    @Mock
    private SpringTemplateEngine templateEngine;

    @InjectMocks
    private EmailService emailService;

    @Test
    void sendSimple_validArgs_sendsMessage() {
        // ARRANGE
        Mockito.doNothing().when(mailSender)
            .send(Mockito.any(SimpleMailMessage.class));

        // ACT
        emailService.sendSimple("user@example.com", "Тест", "Текст письма");

        // ASSERT — проверяем что send() был вызван один раз
        ArgumentCaptor<SimpleMailMessage> captor =
            ArgumentCaptor.forClass(SimpleMailMessage.class);
        Mockito.verify(mailSender).send(captor.capture());

        SimpleMailMessage sent = captor.getValue();
        assertThat(sent.getTo()).contains("user@example.com");
        assertThat(sent.getSubject()).isEqualTo("Тест");
    }

    @Test
    void sendSimple_mailException_throwsException() {
        // SMTP недоступен
        Mockito.doThrow(new MailSendException("SMTP error"))
            .when(mailSender).send(Mockito.any(SimpleMailMessage.class));

        assertThatThrownBy(() ->
            emailService.sendSimple("user@example.com", "Тест", "Текст"))
            .isInstanceOf(MailException.class);
    }
}
❓ Вопросы для собеседования
Как отправить email в Spring Boot? Какие классы используются?
How do you send email in Spring Boot?
Easy▼
✅ Ответ
Добавить spring-boot-starter-mail, настроить SMTP в application.yml. Spring автоматически создаёт бин JavaMailSender. Для простого текста — SimpleMailMessage. Для HTML, вложений — MimeMessage + MimeMessageHelper. Для шаблонов — SpringTemplateEngine (Thymeleaf) рендерит HTML, который передаётся в MimeMessageHelper.
Почему email нужно отправлять асинхронно?
Why should email sending be asynchronous?
Medium▼
✅ Ответ
SMTP запрос занимает 200-2000мс (DNS резолвинг, TCP соединение, аутентификация, передача данных). Если отправлять синхронно в HTTP обработчике — пользователь ждёт. При сбое SMTP — пользователь получит ошибку. Решение: @Async — отправляет в отдельном потоке, HTTP запрос завершается немедленно. Для критически важных писем — очередь с retry (Kafka, RabbitMQ).
Как тестировать отправку email в разработке?
How do you test email sending during development?
Medium▼
✅ Ответ
Использовать MailHog — локальный SMTP сервер который перехватывает письма и показывает их в веб-интерфейсе (localhost:8025). Запускается через Docker. В application-dev.yml указать host: localhost, port: 1025. Реальные письма не отправляются. Альтернативы: Mailtrap.io — облачный сервис для тестирования email. В unit тестах — мокировать JavaMailSender.
В чём разница между SimpleMailMessage и MimeMessage?
What is the difference between SimpleMailMessage and MimeMessage?
Easy▼
✅ Ответ
SimpleMailMessage — только plain text, нет HTML, нет вложений. Простой объект Java, легко создать. MimeMessage — стандарт MIME: поддерживает HTML, вложения (addAttachment), встроенные ресурсы (addInline), несколько получателей CC/BCC, Reply-To, кастомные заголовки. Создаётся через mailSender.createMimeMessage(), настраивается через MimeMessageHelper.
