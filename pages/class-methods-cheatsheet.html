🔤 String — Работа со строками

Основные методы

length() — длина строки

Java
String text = "Hello";
int len = text.length();           // 5

String empty = "";
int emptyLen = empty.length();    // 0

String spaces = "   ";
int spaceLen = spaces.length();   // 3 (пробелы считаются!)

charAt(index) — символ по индексу

Java
String text = "Java";
char first = text.charAt(0);      // 'J'
char third = text.charAt(2);      // 'v'

// Проверка первого символа
String filename = "test.txt";
if (filename.charAt(0) == '.') {
    // Скрытый файл
}

substring(begin, end) — подстрока

Java
String text = "Hello World";
String part1 = text.substring(0, 5);     // "Hello" (end не включается)
String part2 = text.substring(6);        // "World" (до конца)

// Извлечение расширения файла
String file = "document.pdf";
String ext = file.substring(file.lastIndexOf('.') + 1);  // "pdf"

indexOf(str) / lastIndexOf(str) — поиск подстроки

Java
String text = "banana";
int first = text.indexOf("a");           // 1 (первая 'a')
int last = text.lastIndexOf("a");      // 5 (последняя 'a')
int notFound = text.indexOf("z");     // -1 (не найдено)

// Проверка наличия @ в email
String email = "user@example.com";
if (email.indexOf('@') != -1) {
    // Email содержит @
}

contains(str) — содержит ли подстроку

Java
String text = "Hello World";
boolean hasWorld = text.contains("World");    // true
boolean hasJava = text.contains("Java");     // false

// Фильтрация строк
List<String> files = List.of("a.txt", "b.java", "c.txt");
List<String> txtFiles = files.stream()
    .filter(f -> f.contains(".txt"))
    .toList();  // ["a.txt", "c.txt"]

startsWith(prefix) / endsWith(suffix) — проверка начала/конца

Java
String url = "https://example.com";
boolean isHttps = url.startsWith("https://");   // true

String file = "photo.jpg";
boolean isImage = file.endsWith(".jpg") || file.endsWith(".png");  // true

// Валидация номера телефона
String phone = "+7-999-123-45-67";
if (!phone.startsWith("+7")) {
    throw new IllegalArgumentException("Номер должен начинаться с +7");
}

toLowerCase() / toUpperCase() — смена регистра

Java
String login = "UserName123";
String lower = login.toLowerCase();      // "username123"
String upper = login.toUpperCase();     // "USERNAME123"

// Регистронезависимое сравнение
String input = "Admin";
if (input.toLowerCase().equals("admin")) {
    // Пользователь — администратор
}

trim() / strip() — удаление пробелов

Java
String input = "  hello  ";
String trimmed = input.trim();          // "hello" (ASCII пробелы)
String stripped = input.strip();       // "hello" (Unicode пробелы, Java 11+)

// Очистка ввода пользователя
String username = "  JohnDoe  ".trim();  // "JohnDoe"

replace(old, new) — замена подстроки

Java
String date = "2024.01.15";
String formatted = date.replace('.', '-');  // "2024-01-15"

String text = "foo bar foo";
String replaced = text.replace("foo", "baz");  // "baz bar baz"

split(regex) — разделение строки

Java
String csv = "Иван,25,Москва";
String[] parts = csv.split(",");
// parts = ["Иван", "25", "Москва"]

String path = "usr/local/bin";
String[] dirs = path.split("/");
// dirs = ["usr", "local", "bin"]

// Разделение предложения на слова
String sentence = "Java is great";
String[] words = sentence.split("\\s+");  // \\s+ = один или более пробелов
// words = ["Java", "is", "great"]

equals(str) / equalsIgnoreCase(str) — сравнение строк

Java
String s1 = "hello";
String s2 = "hello";
String s3 = "HELLO";

s1.equals(s2);                    // true (одинаковое содержимое)
s1.equals(s3);                    // false (разный регистр)
s1.equalsIgnoreCase(s3);         // true (игнорируем регистр)

// ⚠️ НИКОГДА не сравнивай строки через ==
s1 == s2;                         // Может быть true (String Pool)
new String("hello") == new String("hello");  // ВСЕГДА false!

isEmpty() / isBlank() — проверка на пустоту

Java
"".isEmpty();                      // true (длина 0)
"   ".isEmpty();                    // false (длина 3)
"   ".isBlank();                    // true (только пробелы, Java 11+)

// Валидация ввода
String input = "   ";
if (input == null || input.isBlank()) {
    throw new IllegalArgumentException("Ввод не может быть пустым");
}

Java
String name = "Иван";
int age = 25;
String message = String.format("Привет, %s! Тебе %d лет.", name, age);
// "Привет, Иван! Тебе 25 лет."

// Форматирование чисел
double price = 19.99;
String formatted = String.format("Цена: $%.2f", price);  // "Цена: $19.99"

valueOf(obj) — преобразование в строку (статический)

Java
int num = 42;
String str = String.valueOf(num);           // "42"

boolean flag = true;
String flagStr = String.valueOf(flag);     // "true"

// Конкатенация с null
String result = "Value: " + String.valueOf(null);  // "Value: null"

Java
String result = String.join(", ", "a", "b", "c");  // "a, b, c"

List<String> list = List.of("Java", "Python", "Go");
String langs = String.join(" | ", list);           // "Java | Python | Go"

Java
String text = "Hello";

Java
String text = "abc";

🔢 Math — Математические операции

abs(x) — модуль числа

Java
int neg = -15;
int positive = Math.abs(neg);           // 15

double diff = Math.abs(3.5 - 7.2);    // 3.7 (расстояние)

max(a, b) / min(a, b) — максимум/минимум

Java
int max = Math.max(10, 25);            // 25
int min = Math.min(100, 50);           // 50

// Ограничение значения диапазоном
int value = 150;
value = Math.max(0, Math.min(value, 100));  // 100 (clamp)

pow(x, y) — возведение в степень

Java
double square = Math.pow(2, 10);         // 1024.0
double cube = Math.pow(3, 3);            // 27.0

sqrt(x) / cbrt(x) — квадратный/кубический корень

Java
double sqrt = Math.sqrt(144);           // 12.0
double cbrt = Math.cbrt(27);            // 3.0

// Расстояние между точками (теорема Пифагора)
double distance = Math.sqrt(Math.pow(3, 2) + Math.pow(4, 2));  // 5.0

round(x) / floor(x) / ceil(x) — округление

Java
Math.round(3.7);                   // 4 (ближайшее целое)
Math.floor(3.99);                  // 3.0 (вниз)
Math.ceil(3.01);                   // 4.0 (вверх)

// Округление до 2 знаков после запятой
double price = 19.995;
double rounded = Math.round(price * 100.0) / 100.0;  // 20.0

random() — случайное число [0, 1)

Java
double rand = Math.random();            // 0.0 до 1.0 (не включая 1.0)

// Случайное число от 1 до 100
int dice = (int)(Math.random() * 100) + 1;

// Случайный элемент из массива
String[] colors = {"red", "green", "blue"};
String randomColor = colors[(int)(Math.random() * colors.length)];

sin(x) / cos(x) / tan(x) — тригонометрия (радианы)

Java
double sin90 = Math.sin(Math.PI / 2);     // 1.0
double cos0 = Math.cos(0);              // 1.0
double tan45 = Math.tan(Math.PI / 4);    // 1.0

// Перевод градусов в радианы
double degrees = 90;
double radians = Math.toRadians(degrees);  // 1.570796...

log(x) / log10(x) — логарифмы

Java
Math.log(Math.E);                  // 1.0 (натуральный логарифм)
Math.log10(1000);                  // 3.0 (логарифм по основанию 10)

PI / E — математические константы

Java
double pi = Math.PI;                 // 3.141592653589793
double e = Math.E;                   // 2.718281828459045

// Площадь круга
double radius = 5;
double area = Math.PI * radius * radius;  // 78.539...

parseInt(str) — строка → int

Java
String input = "2026";
int year = Integer.parseInt(input);           // 2026

String ageStr = "25";
int age = Integer.parseInt(ageStr);          // 25

// Обработка ошибки (если строка не число)
try {
    int num = Integer.parseInt("abc");  // NumberFormatException
} catch (NumberFormatException e) {
    System.err.println("Некорректное число");
}

toString(x) — int → строка

Java
int score = 100;
String result = Integer.toString(score);     // "100"

// Конкатенация с текстом
String message = "Ваш счёт: " + Integer.toString(score);  // "Ваш счёт: 100"

// В разных системах счисления
Integer.toBinaryString(10);    // "1010"
Integer.toHexString(255);      // "ff"
Integer.toOctalString(64);     // "100"

valueOf(x) — int → Integer (автобоксинг)

Java
int primitive = 42;
Integer boxed = Integer.valueOf(primitive);  // Integer со значением 42

// Автобоксинг (компилятор делает valueOf автоматически)
Integer auto = 42;  // то же самое, что valueOf(42)

// ⚠️ Integer кэш: -128..127 переиспользуются
Integer a = Integer.valueOf(100);
Integer b = Integer.valueOf(100);
a == b;                     // true (один объект из кэша)

Integer x = Integer.valueOf(200);
Integer y = Integer.valueOf(200);
x == y;                     // false (разные объекты, вне кэша)
x.equals(y);                // true (сравниваем содержимое ✅)

compareTo(x) — сравнение двух Integer

Java
Integer a = 5;
Integer b = 10;
Integer c = 5;

a.compareTo(b);              // -1 (a < b)
b.compareTo(a);              // 1 (b > a)
a.compareTo(c);              // 0 (равны)

// Использование в сортировке
List<Integer> nums = List.of(3, 1, 4);
nums.sort(Integer::compareTo);  // [1, 3, 4]

// Инициализация "бесконечности" для алгоритмов
int minDistance = Integer.MAX_VALUE;

📋 ArrayList — Динамический массив

Основные методы

add(x) — добавить элемент в конец

Java
ArrayList<String> list = new ArrayList<>();
list.add("Apple");                    // list = ["Apple"]
list.add("Banana");                   // list = ["Apple", "Banana"]

// Добавление с авто-расширением массива
for (int i = 0; i < 1000; i++) {
    list.add("Item_" + i);  // ArrayList сам увеличит ёмкость
}

add(index, element) — вставить элемент по индексу

Java
ArrayList<String> list = new ArrayList<>(List.of("A", "C"));
list.add(1, "B");                     // list = ["A", "B", "C"]

// Вставка в начало списка
list.add(0, "First");                  // ["First", "A", "B", "C"]

// ⚠️ Бросит IndexOutOfBoundsException если индекс < 0 или > size()

get(index) — получить элемент по индексу

Java
ArrayList<String> list = List.of("Red", "Green", "Blue");
String color = list.get(1);             // "Green"

// Обход списка через get()
for (int i = 0; i < list.size(); i++) {
    System.out.println(list.get(i));  // Red, Green, Blue
}

// ⚠️ Быстрее использовать for-each: for (String s : list)

set(index, element) — заменить элемент по индексу

Java
ArrayList<Integer> list = new ArrayList<>(List.of(10, 20, 30));
list.set(1, 99);                     // list = [10, 99, 30]

// set() возвращает старое значение
Integer oldValue = list.set(0, 5);    // oldValue = 10, list = [5, 99, 30]

// Обновление всех чётных чисел
for (int i = 0; i < list.size(); i++) {
    if (list.get(i) % 2 == 0) {
        list.set(i, list.get(i) * 2);
    }
}

remove(index) — удалить элемент по индексу

Java
ArrayList<String> list = new ArrayList<>(List.of("A", "B", "C"));
list.remove(1);                       // Удаляет "B", list = ["A", "C"]

// Удаление первого элемента
list.remove(0);                       // list = ["C"]

// ⚠️ При удалении все последующие элементы сдвигаются влево (O(n))

remove(Object) — удалить первое вхождение по значению

Java
ArrayList<String> list = new ArrayList<>(List.of("A", "B", "B", "C"));
boolean removed = list.remove("B");   // true, удаляет ПЕРВОЕ "B"
// list = ["A", "B", "C"]

// Удаление несуществующего элемента
boolean notFound = list.remove("Z");  // false (элемент не найден)

// Удаление всех вхождений через цикл
list.removeIf(s -> s.equals("B"));   // Java 8+, удаляет ВСЕ "B"

size() — количество элементов в списке

Java
ArrayList<String> list = List.of("X", "Y", "Z");
int size = list.size();                // 3

// Проверка на пустоту: лучше isEmpty() чем size() == 0
if (list.isEmpty()) { ... }            // ✅ читаемее и чуть быстрее

// Получение последнего элемента
if (!list.isEmpty()) {
    String last = list.get(list.size() - 1);
}

contains(Object) — содержит ли список элемент

Java
ArrayList<String> list = List.of("Apple", "Banana");
boolean hasBanana = list.contains("Banana");  // true

// contains() использует .equals() для сравнения
boolean noCherry = !list.contains("Cherry");  // true

// Фильтрация: добавить только уникальные
ArrayList<String> unique = new ArrayList<>();
for (String item : sourceList) {
    if (!unique.contains(item)) {  // O(n) — медленно для больших списков!
        unique.add(item);
    }
}
// 💡 Лучше использовать HashSet для проверки уникальности: O(1)

indexOf(Object) / lastIndexOf(Object) — индекс элемента

Java
ArrayList<String> list = List.of("A", "B", "C", "B");
int firstB = list.indexOf("B");        // 1 (первое вхождение)
int lastB = list.lastIndexOf("B");     // 3 (последнее вхождение)
int notFound = list.indexOf("Z");     // -1 (не найдено)

// Поиск с проверкой
if (list.indexOf("Admin") != -1) {
    System.out.println("Админ найден");
}

clear() — удалить все элементы

Java
ArrayList<String> list = new ArrayList<>(List.of("A", "B"));
list.clear();                          // list = [], size = 0

// clear() не обнуляет ёмкость (capacity) — память остаётся
// Для полного сброса: list = new ArrayList<>();

// Очистка перед повторным использованием
public void processBatch(List<String> reusableList) {
    reusableList.clear();  // Очищаем старую порцию данных
    // ... добавляем новые ...
}

Java
ArrayList<Integer> list = new ArrayList<>();

// Валидация перед обработкой
if (!list.isEmpty()) {
    Integer first = list.get(0);  // Безопасно: список не пустой

// isEmpty() предпочтительнее size() == 0:

toArray() — преобразование в массив

📋 Queue / Deque — Очереди и Деки

Основные концепции

Queue — интерфейс FIFO (First In, First Out). Элементы добавляются в конец (хвост) и извлекаются из начала (головы).

Deque (Double Ended Queue) — расширение очереди, позволяющее добавлять и извлекать элементы с обоих концов. Может использоваться как стек (LIFO).

add(x) / offer(x) — добавление элемента

Java
// Queue обычно реализуется через LinkedList или ArrayDeque
Queue<String> queue = new LinkedList<>();

// add(x) — бросает IllegalStateException, если очередь полна (редко для LinkedList)
queue.add("Alice");   // true (добавлено)

// offer(x) — предпочтительный метод! Возвращает false при неудаче, не падает.
queue.offer("Bob");   // true
queue.offer("Charlie"); // true

remove() / poll() — извлечение и удаление головы

Java
// remove() — бросает NoSuchElementException, если очередь пуста
String first = queue.remove();  // "Alice"

// poll() — безопасный метод. Возвращает null, если очередь пуста.
String second = queue.poll();   // "Bob"

// Безопасное извлечение в цикле:
while (queue.size() > 0) {
    String task = queue.poll(); // Всегда безопасно
    process(task);
}

element() / peek() — просмотр головы (без удаления)

Java
// element() — бросает исключение, если пуста
String head = queue.element();  // "Charlie"

// peek() — безопасный просмотр. Возвращает null, если пуста.
String next = queue.peek();     // "Charlie"

stack.push(2);
stack.push(3);

// push/pop — это синонимы addFirst/removeFirst

💡 Best Practice: ArrayDeque vs LinkedList

Java

// ✅ Хорошо: ArrayDeque использует массив, быстрее и меньше памяти

Deque<Integer> stack = new ArrayDeque<>();

📖 BufferedReader / BufferedWriter — Буферизованный ввод/вывод

Почему это важно?

Стандартные FileReader и FileWriter работают с диском очень медленно, запрашивая файл посимвольно. BufferedReader читает данные большими кусками (по умолчанию 8 КБ) и хранит их в памяти ("буфере"), отдавая программе символы уже оттуда. Это ускоряет работу в 10-50 раз!

BufferedReader (Чтение)

readLine() — прочитать строку целиком (самый популярный метод)

Java
// ⚠️ Всегда используй try-with-resources для автоматического close()!
try (BufferedReader reader = new BufferedReader(new FileReader("data.txt"))) {
    
    String line;
    // readLine() возвращает null, когда файл закончился
    while ((line = reader.readLine()) != null) {
        System.out.println("Прочитано: " + line);
    }
}

ready() — готов ли поток к чтению?

Java
try (BufferedReader reader = new BufferedReader(new FileReader("in.txt"))) {
    // Проверяем, есть ли данные, чтобы не блокироваться
    if (reader.ready()) {
        System.out.println("Данные готовы к чтению!");
    }
}

write(str) — записать текст в буфер

    writer.write("Вторая строка");

        String fileName = entry.getName();
        System.out.println("Распаковываю: " + fileName);

            }
        }

// YWFhYWFhYWFhYWFhYWFhYWFhYWFhYWFhYWFhYWFhYWFhYWFhYWFhYWFh...
Когда использовать Base64?
⚠️ Важно помнить
1. Base64 — это НЕ шифрование! Данные можно легко декодировать обратно. Это просто "перевод" бинарных данных в текст.
2. Увеличение размера: Данные в Base64 занимают на ~33% больше места, чем исходные байты.
3. Где нужно: Передача картинок в JSON, хранение двоичных данных в БД (если поле только текстовое), передача токенов в URL.

Главная проблема: Thread Safety
❌ Опасность в многопоточности
SimpleDateFormat НЕ потокобезопасен!

❓ Вопросы для собеседования

В чём разница между == и .equals() для строк?
Difference between == and .equals() for Strings?
Easy ▼
✅ Ответ
== сравнивает ссылки (адреса в памяти), .equals() сравнивает содержимое строк. Для строк всегда используй .equals() или Objects.equals(). == может вернуть true для литералов из String Pool, но false для new String("text").
Почему String immutable (неизменяемый)?
Why is String immutable?
Medium ▼
✅ Ответ
1) Безопасность: строки используются как ключи в HashMap, параметры подключения к БД. 2) String Pool: экономия памяти через переиспользование. 3) Thread-safe: можно безопасно использовать в многопоточном коде без синхронизации. 4) Кэширование hashCode: можно кэшировать хэш-код для производительности.
В чём разница между ArrayList и LinkedList?
Difference between ArrayList and LinkedList?
Medium ▼
✅ Ответ
ArrayList: динамический массив. Быстрый доступ O(1) по индексу, медленная вставка/удаление в середине O(n). LinkedList: двусвязный список. Быстрая вставка/удаление O(1) (если известен узел), медленный доступ O(n). ArrayList использует меньше памяти (нет указателей на next/prev).
Как работает HashMap внутри?
How does HashMap work internally?
Hard ▼
✅ Ответ
HashMap использует массив бакетов (bucket array). При put(key, value): 1) Вычисляется hashCode(key), 2) Определяется индекс бакета: index = hashCode % capacity, 3) Если бакет пуст — создаётся узел, 4) Если есть коллизия — цепочка (LinkedList) или дерево (TreeNode если > 8 элементов). При get(key) — обратный процесс. Load factor 0.75 — при заполнении 75% происходит resize (удвоение capacity).
Зачем нужен Optional и как его правильно использовать?
What is Optional and how to use it correctly?
Medium ▼
✅ Ответ
Optional — контейнер для значения, которое может быть null. Делает отсутствие значения явным в сигнатуре метода. Правильное использование: 1) Возвращать из методов вместо null, 2) Использовать map(), filter(), orElse(), orElseGet(), 3) НЕ использовать в полях класса, 4) НЕ использовать в параметрах методов. Избегай .get() без проверки — используй orElse() или ifPresent().
В чём разница между Stream и Collection?
Difference between Stream and Collection?
Hard ▼
✅ Ответ
Collection: хранит данные в памяти, можно итерировать многократно, можно изменять. Stream: не хранит данные, вычисляет "на лету", можно использовать только один раз (одноразовый), ленивые операции (промежуточные операции выполняются только при терминальной). Stream — это функциональный подход к обработке данных, Collection — структура данных.
